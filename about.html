About This Project

This website is a clone of the Nike India online store, made as a mini project for the BSc IT course. It is built only with HTML, CSS and JavaScript. There is no server and no database, so all data (users, bag and orders) is stored in the browser using localStorage, and the login data can be downloaded as a CSV file that opens in MS Excel.

Important : This is only a study project. It is not the real Nike website and it has no connection with Nike Inc. The brand name, product names and design are used here only to practise front end web development for college submission, not for any business purpose. No real order or payment takes place on this site.

Features

  • Home page with hero banner, trending products and categories
  • Product listing with search, category filter and price sorting
  • Product detail page with size selection and quantity
  • Add to Bag with quantity increase / decrease and remove option
  • Automatic calculation of subtotal, delivery charge and total
  • Checkout page with full form validation
  • Order confirmation page with order number and print bill option
  • Sign In and Join Us, data saved into data.csv (email + password)
